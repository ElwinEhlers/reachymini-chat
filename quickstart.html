Reachy Mini — Quickstart

Referenz

Starten

1
Simulation starten (Daemon)
uv run reachy-mini-daemon --sim
uv run reachy-mini-daemon --sim --scene minimal
Dashboard: http://localhost:8000
2
Ollama sicherstellen (separates Terminal)
curl http://localhost:11434/v1/models
API: http://localhost:11434
3
Chat-App starten (aus reachy_chat/)
cd /home/sbin/reachy/reachy_chat
uv run reachy-chat
Chat-UI: http://localhost:8042

URLs

💬 Chat-UI localhost:8042 Browser-Oberfläche der Chat-App 🤖 Daemon-Dashboard localhost:8000 Simulation & Roboter-Status 🧠 Ollama localhost:11434 Lokales LLM (qwen3:8b)

Mikrofon (Push-to-Talk)

🎤 Mikrofon-Knopf gedrückt halten → sprechen
✋ Loslassen → Sprache wird erkannt (Whisper STT)
🔊 Antwort wird automatisch vorgelesen (Piper TTS, Deutsch)
🔇 Lautsprecher-Knopf rechts schaltet TTS stumm
Rot, pulsierend — hört zu (listening)
Gelb — verarbeitet (STT / LLM läuft)
Grün — spricht (TTS läuft)
Arbeitsverzeichnis: /home/sbin/reachy  ·  Modell: qwen3:8b-q4km  ·  Simulation: MuJoCo
